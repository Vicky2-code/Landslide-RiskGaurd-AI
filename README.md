# Landslide RiskGuard AI

A full-stack landslide risk monitoring and early warning system for India's North Eastern Region (NER).

## Tech Stack

- **Frontend:** React + TypeScript + Vite, Tailwind CSS, Leaflet.js, Recharts
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL + PostGIS
- **ML:** scikit-learn (Random Forest)
- **Auth:** JWT-based, two roles: `authority` and `citizen`

## Quick Start

### Prerequisites
- Python 3.10+
- Node.js 18+
- PostgreSQL with PostGIS extension

### 1. Database Setup
```sql
CREATE DATABASE landslide_riskguard;
\c landslide_riskguard
CREATE EXTENSION postgis;
```

### 2. Backend
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
alembic upgrade head
python seed.py
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend
```bash
cd frontend
npm install
npm run dev
```

### 4. Access
- Frontend: http://localhost:5173
- API docs: http://localhost:8000/docs

## Features

1. **Authority Dashboard** — Interactive map with risk-colored zone markers, stat cards, district/risk filters
2. **Zone Detail** — Risk score breakdown, rainfall/soil moisture charts, 7-day trend, infrastructure at risk
3. **Citizen Report** — Mobile-first form with GPS, photo upload, offline queue
4. **Alerts Panel** — Live alert feed with acknowledge action, auto-generated by background scheduler
5. **Reports Review Queue** — Authority-only queue to approve/reject citizen reports

## Background Scheduler

A background job runs every 60 seconds, re-scoring all zones using the latest seeded readings. When a zone's risk score exceeds 70, a new alert is created with an English + regional language message.

## Design System

The UI follows a custom design system with:
- Navy sidebar (#16302b) with teal accent (#0d9488)
- Flat white cards with hairline borders (no shadows)
- Risk-colored indicators (green/amber/orange/red) reserved for risk levels only
- Serif headings (Source Serif 4) + sans-serif body (Inter)
- Pill-shaped buttons with teal primary color
